# UI/UX 与动效规范

- 信息色：`#9d4edc`

## 页面结构模板
- 顶部：全局操作（头像、退出、主题）
- 左侧：权限驱动菜单 + 插件菜单
- 内容区：页面标题、筛选、主体卡片、空态/错误态/加载态

## 动效规范
- 页面切换时长：`0.2s`
- 基础动画：淡入 + 轻微位移
- 动画库：`framer-motion`
- 原则：动效不可阻塞业务交互；低性能设备可降级

## 可访问性
- 关键交互可键盘操作
- 颜色对比满足可读性
- 错误消息必须显式可见
